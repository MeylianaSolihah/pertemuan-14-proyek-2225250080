# Proposal Proyek

## 1. Judul
Program Rekap dan Analisis Nilai Matematika Kelas

## 2. Latar Belakang
Pengolahan nilai matematika secara manual membutuhkan waktu dan berisiko menimbulkan kesalahan. Program ini dirancang untuk membantu proses pengolahan nilai secara sederhana.

## 3. Pengguna dan Tujuan
Pengguna program adalah guru atau mahasiswa yang membutuhkan pengolahan nilai siswa. Tujuannya adalah menghitung statistik nilai dan menentukan status ketuntasan siswa.

## 4. Ruang Lingkup
Program membaca data nama dan nilai siswa, memvalidasi nilai dalam rentang 0–100, menghitung rata-rata, nilai minimum dan maksimum, serta menentukan status ketuntasan berdasarkan batas nilai 75.

## 5. Kebutuhan
- Python 3.
- Editor kode seperti Visual Studio Code.
- File teks berisi nama dan nilai siswa.

## 6. Input, Proses, dan Output
- Input: nama siswa dan nilai matematika.
- Proses: validasi data, perhitungan statistik, dan penentuan ketuntasan.
- Output: daftar nilai, statistik kelas, dan status ketuntasan.

## 7. Algoritma
1. Baca data nilai siswa.
2. Periksa apakah nilai berupa angka dan berada pada rentang 0–100.
3. Simpan data yang valid.
4. Hitung rata-rata, nilai minimum, dan maksimum.
5. Tentukan status tuntas jika nilai minimal 75.
6. Tampilkan hasil analisis.

## 8. Struktur Program
- main.py: menjalankan program.
- data_io.py: membaca data nilai.
- analisis.py: mengolah dan menganalisis nilai.
- utilitas.py: fungsi pendukung.

## 9. Struktur Data
Data siswa disimpan dalam list yang berisi dictionary dengan kunci nama dan nilai.

## 10. Rencana Pengujian
Pengujian mencakup data normal, nilai batas ketuntasan, nilai 0, nilai 100, dan data tidak valid.

## 11. Pembagian Tugas
Pembagian tugas dilakukan sesuai anggota tim dan disepakati bersama.

## 12. Jadwal
- Tahap 1: perencanaan dan penyusunan proposal.
- Tahap 2: pembuatan program.
- Tahap 3: pengujian dan perbaikan.
- Tahap 4: dokumentasi dan pengumpulan.
