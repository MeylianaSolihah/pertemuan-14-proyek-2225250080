## Judul Proyek
Program Rekap dan Analisis Nilai Matematika Kelas

## Deskripsi
Program ini dibuat untuk membantu proses pengolahan nilai matematika siswa secara sederhana, mulai dari membaca dan memvalidasi data hingga menghitung statistik nilai dan menentukan status ketuntasan.

## Fitur Program
- Membaca data nilai siswa.
- Memvalidasi nilai dalam rentang 0–100.
- Menghitung rata-rata, nilai minimum, dan maksimum.
- Menentukan status ketuntasan siswa.
- Menampilkan hasil analisis nilai.

## Struktur Program
- `data/`: menyimpan data nilai contoh.
- `src/`: menyimpan kode program Python.
- `tests/`: menyimpan rancangan pengujian.
- `output/`: tempat untuk menyimpan hasil keluaran.
- `proposal.md`: berisi rancangan proyek.

## Cara Menjalankan
Pastikan Python sudah terpasang. Jalankan perintah berikut dari terminal di folder proyek:

python src/main.py
